# Искра Монтаж

Личный редактор Reels для мастерской мебели и металлоизделий: нарезки с телефона режутся в бит трека,
с цветокором, переходами и текстом. Работает в браузере, ничего не отправляет наружу, кроме кадров
при нажатии «Понять кадры и собрать ролик».

## Как запустить

- **Проще всего:** двойной клик по `index.html`. Откроется в браузере (лучше Chrome).
  В этом режиме из музыки доступны раздел «Синтезатор» и свой трек — авторские треки браузер из папки не читает.
- **Через локальный сервер:** `Запуск-Windows.bat` или `Запуск-Mac.command` (нужен установленный Python).
  Тогда работает вся библиотека из папки `music/`.
- **На телефоне как приложение:** папку целиком нужно положить на сайт с https. Потом открыть адрес
  на телефоне и выбрать «На экран Домой» / «Установить приложение». После первого открытия работает без интернета.

## Что где лежит

| Путь | Что это |
|---|---|
| `index.html` | Разметка экрана: вкладки, кнопки, поля |
| `css/app.css` | Внешний вид: цвета, отступы, шрифты интерфейса |
| `js/config.js` | **Настройки-данные**: стили монтажа, переходы, цветокоры, шрифты, каталог музыки `LIB`, заготовки текста, сценарии |
| `js/tracks.js` | Загрузка треков из `music/`, синтезатор, список треков на экране |
| `js/audio.js` | Поиск темпа и дропа в треке |
| `js/timeline.js` | Раскладка склеек по битам, правка отдельных кадров, текст на экране, эффекты переходов |
| `js/gl.js` | Шейдер: цветокор, размытие, вспышка |
| `js/clips.js` | Загрузка видео и фото |
| `js/player.js` | Проигрывание и волна трека |
| `js/export.js` | Запись ролика в MP4 и сохранение |
| `js/auto.js` | Авто-ролик: распознавание изделия по кадрам и текст запроса |
| `js/ui.js` | Кнопки и запуск |
| `music/` | Библиотека: 26 фрагментов треков Kevin MacLeod (CC BY 4.0) и шесть треков синтезатора. Авторы и лицензия — в `music/CREDITS.txt` |
| `fonts/` | Шрифты с кириллицей |
| `sw.js`, `manifest.webmanifest`, `icons/` | Установка на телефон и работа без интернета |

## Частые правки

- **Свои заготовки текста:** `js/config.js`, список `IDEAS`.
- **Свой сценарий** (ритм + цвет + трек + текст одной кнопкой): `js/config.js`, список `SCENS`.
- **Свой цветокор:** `js/config.js`, список `LOOKS` — контраст `con`, насыщенность `sat`, теплота `temp`, виньетка `vig`, зерно `grain`.
- **Ритм склеек:** `js/config.js`, `STYLES` — `pat` это длины кадров в ударах.
- **Новый переход:** название в `TRANS` (`js/config.js`) и его формула в `switch(seg.fx)` в `js/timeline.js`.
- **Как приложение просит текст у нейросети:** строка запроса в `js/auto.js`.
- **Добавить свой трек в библиотеку:** положи MP3 в `music/`, например `music/moy-trek.mp3`, и добавь строку
  в список `LIB` в `js/config.js`: `{"id":"moy-trek","t":"Название","a":"Автор","cat":"energy","bpm":120,"len":60}`.
  `bpm` — темп трека (если не знаешь, поставь примерно: приложение уточнит), `cat` — раздел из списка `CATS`.
- **Эффект поверх кадра:** название в `OVFX` (`js/config.js`), формула в шейдере `js/gl.js`.

## Музыка и права

Треки в библиотеке — настоящие, автор Kevin MacLeod, лицензия Creative Commons Attribution 4.0. Их можно ставить
в рекламные ролики, но в описании ролика нужно указать автора. Готовую подпись приложение показывает
на вкладке «Музыка» и после сборки ролика. Треки раздела «Синтезатор» подписи не требуют.

Треки из библиотеки читаются, только когда приложение запущено с сайта или через файл «Запуск».
При двойном клике по `index.html` доступны «Синтезатор» и свой трек.

После правок, если приложение установлено на телефон, поменяй `VERSION` в `sw.js`.

## Распознавание кадров

По ссылке на Claude распознавание работает само. В этой папке для него нужен ключ сервиса Pollinations —
поле появляется под кнопкой «Понять кадры и собрать ролик». Без ключа всё остальное работает.
