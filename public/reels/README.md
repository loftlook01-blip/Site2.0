# Искра Монтаж

Личный редактор Reels для мастерской мебели и металлоизделий, по схеме Beatleap:
нарезки → трек → готовый ролик в бит, дальше правишь в редакторе.

## Как запустить

- **На компьютере:** двойной клик по `index.html` (лучше Chrome). Работает всё, включая библиотеку треков.
- **Через локальный сервер** (необязательно): `Запуск-Windows.bat` или `Запуск-Mac.command`, нужен Python.
- **На телефоне как приложение:** папку целиком положить на сайт с https, открыть адрес на телефоне
  и выбрать «На экран Домой». После первого открытия работает без интернета.

## Как пользоваться

0. **Мои ролики** на главном экране — черновики. Всё сохраняется само: нарезки, трек, правки.
   Закрыл окно — открыл снова — продолжаешь с того же места. «Удалить» убирает черновик вместе с видео.
1. **Новый ролик** → добавь видео и фото. Номер на кадре — порядок; «Перемешать» — случайный порядок.
   «Понять кадры и собрать ролик» — авто-ролик: изделие, порядок и текст подберёт нейросеть.
2. **Выберите музыку** → раздел, трек (кружок слева — послушать) → «Далее».
3. **Редактор.** Ролик сразу играет. Внизу три вкладки:
   - **Инструм.** — Медиа, Править (выбрать кадр, подвинуть рамку на ленте клипа, заменить клип,
     переставить), Длина, Сегмент (какой кусок трека), Настрой (темп монтажа и ритм склеек),
     Переходы, Затухание, Формат, Текст (шрифт, оформление, анимация: удар, выезд, прыжок, печать;
     хук сверху, по центру или снизу), Бренд (логотип в углу, финальная заставка с логотипом, ценой
     и контактами), ИИ-текст. В листе: ✕ — отменить, ✓ — применить.
   - **Правка** — удерживай кружок эффекта, пока идёт ролик: эффект ляжет на это место цветной полосой
     на шкале. Короткое нажатие — на один удар. Отмена — стрелкой ↶ вверху.
     «Бумеранг» снимает пол-удара видео и гоняет его туда-обратно, пока держишь кнопку.
   - **Фильтры** — цветокор с ползунком силы.
   Шкалу можно тянуть пальцем. Пробел — пауза, Ctrl+Z / Ctrl+Shift+Z — отмена и повтор.
4. **Сохранить** → «Записать ролик» → «Сохранить видео». Если трек из библиотеки — скопируй подпись об авторе в описание.

## Умный монтаж

- При добавлении нарезок приложение смотрит каждую: где больше движения и резкости. Оттуда и берёт кадры.
- В громких местах трека склейки чаще, в тихих — реже; на сильных ударах — короткий толчок кадра.
- Перед дропом — замедление, на дропе — вспышка и наезд.
Выключается в «Настрой».

## Что где лежит

| Путь | Что это |
|---|---|
| `index.html` | Разметка экранов |
| `css/app.css` | Внешний вид |
| `js/config.js` | **Настройки-данные**: ритмы `STYLES`, переходы `TRANS`, эффекты `EFFECTS`, фильтры `LOOKS`, шрифты, каталог музыки `LIB`, заготовки текста `IDEAS`, сценарии `SCENS` |
| `js/timeline.js` | Раскладка склеек по битам, умный монтаж, текст, отрисовка эффектов |
| `js/player.js` | Проигрывание, шкала, эффекты «Правки», отмена и повтор |
| `js/drafts.js` | Черновики в браузере (IndexedDB) и логотип |
| `js/clips.js` | Загрузка и анализ нарезок |
| `js/audio.js` | Поиск темпа, дропа и силы ударов |
| `js/tracks.js` | Загрузка треков и синтезатор |
| `js/gl.js` | Шейдер: цветокор и эффекты |
| `js/export.js` | Запись ролика и сохранение |
| `js/auto.js` | Авто-ролик и текст запроса к нейросети |
| `js/ui.js` | Экраны, инструменты, листы |
| `music/` | Треки: `.mp3` для сайта и такие же `.js` для запуска двойным кликом. Авторы — в `music/CREDITS.txt` |
| `fonts/` | Шрифты с кириллицей |

## Частые правки

- **Заготовки текста:** `IDEAS` в `js/config.js`.
- **Свой фильтр:** `LOOKS` — контраст `con`, насыщенность `sat`, теплота `temp`, виньетка `vig`, зерно `grain`.
- **Свой трек в библиотеку:** положи `music/moy-trek.mp3`, сделай рядом `music/moy-trek.js`
  (строка `(window.ISKRA_TRACKS=window.ISKRA_TRACKS||{})['moy-trek']='<MP3 в base64>';`)
  и добавь в `LIB`: `{"id":"moy-trek","t":"Название","a":"Автор","cat":"energy","bpm":120,"len":60}`.
  Без `.js` трек будет работать только через «Запуск» или с сайта.
- **Новый эффект «Правки»:** название и цвет в `EFFECTS`, формула в `frame()` в `js/timeline.js`.

После правок, если приложение установлено на телефон, поменяй `VERSION` в `sw.js`.

## Где хранятся черновики

В самом браузере (IndexedDB), на этом компьютере. Другой браузер или другой компьютер их не видит.
Очистка данных сайта в браузере удаляет и черновики. Если место кончится, приложение предупредит —
ролик всё равно можно доделать и записать.
