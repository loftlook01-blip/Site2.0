# ДВИНА — сайт кухонь и корпусной мебели на заказ (Архангельск, Северодвинск, Новодвинск)

**Стек:** Astro 7 (статическая генерация) · TypeScript · чистый CSS · JS только для конструктора, форм и анимаций.

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # готовый сайт в dist/
```

## Где что менять
Весь контент — в `src/data/`: `site.ts` (бренд, телефон, адрес — **все TODO заменить перед запуском**), `cities.ts`, `catalog.ts`, `content.ts` (цены, этапы, FAQ), `articles.ts`.

## SEO и GEO
Отдельная страница под каждый запрос (стиль / планировка / мебель / город), JSON-LD (LocalBusiness, Product, Service, FAQPage, HowTo, Article, BreadcrumbList), sitemap, robots с Clean-param, YML-фид `/feed.yml`, RSS, `llms.txt` и `llms-full.txt` для нейросетей.

## Изображения
Фотографии в `public/images/` сгенерированы нейросетью (`scripts/gen-images.py`, модель nano-banana-2.1): для каждой кухни и мебели — основной кадр и до двух других ракурсов (`<имя>`, `<имя>-2`, `<имя>-3`), за окнами — типовая застройка Архангельска.
Перегенерация: `IMG_API_KEY=… python3 scripts/gen-images.py <папка> [имя …]`, затем `npm run images <папка>`. Ракурсы на странице показываются автоматически, если файлы есть.
Когда появятся фото реальных работ — положите их под теми же именами.

## Калькулятор, запись на замер и Telegram-бот
- **Быстрый расчёт** на главной (`QuickCalc.astro`): 4 вопроса → ориентир цены → запись на замер (город, день, время). **Конструктор** (`/konstruktor/`) — то же со схемой кухни. Цены — в `src/data/content.ts` (`CALC`): одни и те же для сайта и бота (при сборке они попадают в `dist/api/calc.json`).
- **Заявки** уходят на `/api/lead.php` → менеджерам в Telegram (с кнопками «Взял в работу / Замер назначен / Не дозвонился / Отказ», статус обновляется во всех чатах) + копия в `api/leads/` + e-mail по желанию. С заявкой едут расчёт, источник и UTM-метки.
- **Бот для клиентов** (`/api/tg.php`): `/start` → расчёт кухни кнопками → ориентир цены → запись на замер → телефон одной кнопкой → заявка менеджеру.

### Запуск бота (5 минут)
1. В Telegram: **@BotFather → /newbot** — получите токен. Ссылку на бота впишите в `src/data/site.ts → telegramBot` (`https://t.me/имя_бота`) — на сайте появится кнопка.
2. На хостинге (нужен PHP 8.0+ и HTTPS) скопируйте `public/api/config.example.php` в `api/config.php`, впишите `telegram_token` и `webhook_secret` (любая длинная случайная строка).
3. Зарегистрируйте вебхук: `TG_TOKEN=… TG_SECRET=<тот же секрет> SITE_URL=https://ваш-домен bash scripts/tg-setup.sh`
4. Узнайте chat_id: напишите боту `/id` (или добавьте бота в рабочую группу и напишите `/id` там). Впишите его в `telegram_chat` (несколько — через запятую): туда будут приходить заявки.
5. Проверка: отправьте заявку с сайта и пройдите `/calc` в боте.

Папки `api/leads/` и `api/state/` закрыты от веба через `.htaccess`. На nginx добавьте `location ~ ^/api/(leads|state|_lib|config) { deny all; }`.
